# Phase 8 Navigation Map

- `index.html` — Main title menu
- `lobby.html` — Skirmish lobby / seat setup
- `skirmish.html` — Flat RTS runtime
- `globe.html` — Globe Conquest runtime
- `battlemaps.html` — Premade battle challenge library
- `builder.html` — Geography/world Map Editor
- `battle-editor.html` — Battle Map challenge editor
- `scenario.html` — Advanced Scenario Studio
- `factions.html` — Faction Hall
- `howto.html` — Overall player guide
- `settings.html` — Settings shell

## Mental model

**Map Editor** builds the place.

**Battle Map Editor** builds the fight that happens there.

**Scenario Studio** adds deep rules when a challenge needs them.

**Skirmish** is free-form play.

**Battle Maps** are curated premade battle challenges.

**Faction AI** is native to a faction.

**Connected AI** occupies a normal player seat.
