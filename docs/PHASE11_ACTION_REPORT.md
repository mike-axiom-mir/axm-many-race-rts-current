# Phase 11 Action Report

## Built

Three additive starter factions were added without modifying the historical/current four-faction lineage.

- Ironvale Compact — balanced / defense
- Greenwake Union — economy / sustain
- Ashwind League — mobility / aggression

Each starter includes:
- faction data;
- founder identity;
- economy / military / building profile;
- three faction-specific buildings;
- two unit formations;
- live runtime mechanic;
- native faction NPC strategist;
- automatic integration into data-driven faction/content systems.

## Runtime mechanics

- Ironvale: Compact Discipline — nearby friendly infrastructure gives formations a modest combat/range bonus.
- Greenwake: Living Supply — formations near economy districts slowly recover health.
- Ashwind: Forward Momentum — formations far from their capital gain damage and speed.

## Preserved

Northpole Dominion, Suitcase Habitat Collective, Fatfrotz Empire and Clockwork Orchard Assembly were not rewritten or renamed.

## Intended next step

Use these starter factions for initial real gameplay and balance runs while older faction source material is recovered separately.

## Verification boundary

Repository/module structure was reviewed in-chat. No successful browser/local runtime test is claimed here. The first real playtest should focus on build timing, economy pacing, unit readability and whether each starter mechanic is noticeable without being dominant.
